# Capacidades de TaskFlow Lite

**Capacidades derivadas del Product Goal**

| # | Capacidad | Clasificación | Valor |
|---|-----------|---------------|-------|
| 1 | Registrar tarea (nombre obligatorio; descripción y fecha límite opcionales; estado inicial Pendiente) | Esencial para MVP | Permite sacar las tareas de chats y notas sueltas hacia un único lugar. |
| 2 | Visualizar tareas con nombre, descripción, fecha límite y estado en una sola vista | Esencial para MVP | Da claridad inmediata de qué hay pendiente, en curso y terminado. |
| 3 | Avanzar el estado de una tarea (Pendiente → En proceso → Finalizada, solo hacia adelante) | Esencial para MVP | Permite dar seguimiento real al avance del trabajo. |
| 4 | Persistir las tareas entre sesiones | Esencial para MVP | Hace confiable la herramienta: la información no se pierde al cerrar el navegador. |
| 5 | Editar nombre, descripción y fecha límite de una tarea | Esencial para MVP | Permite corregir o actualizar la información sin recrear la tarea. |
| 6 | Eliminar tarea (con confirmación previa) | Esencial para MVP | Mantiene la lista limpia y evita borrados accidentales. |
| 7 | Indicar visualmente tareas con fecha límite vencida | Posterior | Ayuda a priorizar, pero el Product Goal no lo exige. |
| 8 | Ordenar o filtrar tareas (por estado o por fecha límite) | Posterior | Facilita la lectura cuando la lista crece, pero la vista única ya cubre el indicador 2. |
