# Capacidades de TaskFlow Lite

| Capacidad | Clasificación | Valor |
| --- | --- | --- |
| Registrar una tarea (título y, opcionalmente, responsable) | **Esencial para MVP** | Permite capturar el trabajo pendiente en pocos pasos. |
| Visualizar la lista de tareas con su estado | **Esencial para MVP** | Da al equipo una vista única de qué existe y en qué punto está. |
| Actualizar el estado de una tarea (Por hacer, En curso, Hecha) | **Esencial para MVP** | Refleja el avance real y responde "¿qué está pendiente?". |
| Asignar un responsable a una tarea | **Esencial para MVP** | Aclara quién hace qué, uno de los problemas centrales del Product Goal. |
| Conservar las tareas al cerrar o recargar el navegador | **Esencial para MVP** | Sin persistencia el producto no sirve para dar seguimiento. |
| Editar o eliminar una tarea | **Posterior** | Corrige errores y limpia tareas obsoletas, pero el MVP puede operar sin ello al inicio. |
| Filtrar por estado o responsable | **Posterior** | Facilita la lectura cuando crece el número de tareas. |
| Compartir tareas entre personas o dispositivos | **Posterior** | Responde al valor de "visualizar en equipo", pero exige resolver antes la decisión de almacenamiento. |
